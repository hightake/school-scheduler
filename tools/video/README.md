# הפקת סרטון ההדרכה

הסקריפט פותח את התוכנה בדפדפן ועובר על כל השלבים. הוא מזיז סמן, מסמן את המקום הרלוונטי במסך ומציג כתוביות. אחר כך הוא משלב את הקריינות ושומר:

- `docs/video/tutorial.mp4` – הסרטון.
- `docs/video/tutorial.srt` – כתוביות.
- `docs/video/NARRATION.md` – תסריט הקריינות עם ציר זמן.

## דרישות

Node.js עם Playwright, ffmpeg, ו-Python עם `pip install edge-tts`. ה-edge-tts צריך חיבור לאינטרנט.

## הרצה

```bash
node tools/video/make-video.js . docs/video
```

## קריינות שלכם במקום הקול הממוחשב

1. מקליטים כל קטע מהתסריט (`docs/video/NARRATION.md`) כקובץ נפרד.
2. שומרים את הקבצים בתיקייה `tools/video/voice/` לפי מספר הקטע: `01.mp3`, `02.mp3` וכן הלאה. אפשר גם m4a או wav.
3. מריצים שוב את הסקריפט.

כל קטע שיש לו הקלטה ישתמש בה. הסרטון מתאים את עצמו לאורך של כל הקלטה, כך שאין צורך לדייק בשניות. קטעים בלי הקלטה ימשיכו להשתמש בקול הממוחשב.

את הטקסטים ואת הפעולות על המסך עורכים במערך `scenes` שבראש `make-video.js`. כשהתוכנה משתנה, מריצים מחדש ומקבלים סרטון מעודכן.
