# שיבוץ – מערכת שעות חכמה למוסד חינוכי

תוכנה לבניית מערכות שעות שמתחשבת באילוצים של **תלמידים, מורים, מטפלים, כיתות וחדרים**. כרגע היא מותאמת למוסד חינוך מיוחד שמשלב תלמידים בחלק מהיום בכיתות רגילות. המבנה כללי, ולכן התוכנה מתאימה גם לכל מוסד או עסק שצריך מערכת שעות עם הרבה אילוצים.

## הפעלה

אין צורך בהתקנה או באינטרנט:

1. מורידים את התיקייה (Code → Download ZIP) ופותחים את הקובץ ‎`index.html`‎ ב-Chrome או ב-Edge.
2. במסך הראשון לוחצים "טעינת נתוני דוגמה" כדי להתנסות, או מתחילים מאפס בהגדרות.

הנתונים נשמרים **בדפדפן במחשב זה בלבד** ולא נשלחים לשום שרת, וזה חשוב לפרטיות התלמידים. מומלץ להוריד "גיבוי" באופן קבוע.

## מה יש בתוכנה

| תחום | יכולות |
|---|---|
| **נתונים** | תלמידים (כיתת אם, אילוצי זמן, הערות), צוות (תפקיד, תחומי התמחות, ימי ושעות נוכחות, מכסת שעות), כיתות (חנ"מ / רגילות), חדרים, מערכת צלצולים (שיעורים, הפסקות, תפילה/ארוחה, לפי ימים), חגים |
| **פעילויות ודרישות** | שיעור כיתתי, שגרה, שילוב בכיתה רגילה (אפשר לקשר לשיעור מסוים בכיתה הרגילה), טיפול, עזרה/תגבור, חוג, הדרכת צוות, ישיבה. לכל פעילות מגדירים משתתפים, משך, מספר מפגשים בשבוע, שבועות א/ב, ימים מותרים או מועדפים, חלון שעות, "מוגן" (אסור לצאת ממנו), גודל קבוצה ותלמידים פטורים |
| **שיבוץ אוטומטי** | משבץ את כל החסר ומעדיף שלא להוציא תלמידים משיעורים, במיוחד לא משילוב. נמנע מהפסקות ומפזר את המפגשים על פני השבוע. מפגשים נעולים לא זזים |
| **לוח שיבוץ** | תצוגה שבועית לפי כיתה, איש צוות, תלמיד או חדר. אפשר לגרור מפגש למקום אחר, והתוכנה בודקת התנגשויות מיד. התנגשויות מסומנות באדום |
| **בדיקת זמן** | בוחרים זמן ואנשים, ומקבלים לכל אחד אם הוא פנוי, תפוס או אפשרי. בודקים אם אפשר לשבץ פעילות בזמן מסוים, ואם לא, **אילו מפגשים צריך להזיז (מינימום שינויים)**. אפשר גם לראות מי מהצוות פנוי ומתי כל הנבחרים פנויים יחד |
| **המלצות** | מכניסים המלצה לתלמיד (תחום ותדירות). התוכנה מזהה את אנשי המקצוע בתחום שיש להם זמן פנוי, ומציעה הצטרפות לקבוצה קיימת או מפגש חדש. השיבוץ נעשה בלחיצה |
| **שינויים לפי תאריך** | הדרכות משתנות, ביטול או הזזה חד-פעמיים, היעדרות איש צוות עם הצעת מחליף פנוי מאותו תחום |
| **הפקה** | 1. תלמיד 2. כיתתית (כל הכיתה או רובה) 3. מחנך חנ"מ (הכל, כולל הדרכות קבועות ומשתנות) 4. מורה בכיתה רגילה (קומפקטי: מתי התלמיד בכיתה ומתי ולאן הוא יוצא) 5. איש צוות/מטפל 6. חדר. טווחים: שבוע, יום, שעות, תאריך, שבוע בתאריכים, חודש. פורמטים: **PDF/הדפסה, Excel, Word**. אפשר להפיק לכולם בבת אחת |
| **ייבוא** | Excel, CSV, PDF, Word (docx) או טקסט מודבק. העמודות (שם, כיתה, תפקיד, תחום...) מזוהות אוטומטית, ואפשר לבחור אילו שורות לייבא |
| **בטיחות** | ביטול ושחזור (Ctrl+Z / Ctrl+Y), שמירת גרסאות, גיבוי ושחזור לקובץ, יומן שינויים |
| **דוחות** | עומס שעות לכל איש צוות, שעות טיפול ושילוב לכל תלמיד, **מה כל תלמיד מפספס** בגלל יציאות, וכיסוי הדרישות |

## איך התוכנה "חושבת" (שכבות)

- **שכבה 0 – כיתת אם**: שיעורים ושגרה.
- **שכבה 1 – שילוב**: התלמיד נמצא בכיתה הרגילה.
- **שכבה 2 – יציאה**: טיפול, עזרה או חוג. התלמיד יוצא מכל מקום שבו הוא נמצא.

שתי פעילויות באותה שכבה ובאותו זמן הן התנגשות. יציאה משיעור רגיל מותרת, אבל היא נספרת כעלות שהתוכנה מנסה לצמצם. יציאה משיעור מוגן אסורה.

הסבר מפורט צעד אחר צעד: מושגים, סדר עבודה, מצבים נפוצים וטיפים. נמצא ב-**[docs/GUIDE.md](docs/GUIDE.md)**.

## למפתחים

- `js/engine.js`: מנוע האילוצים והשיבוץ. זו לוגיקה טהורה שאפשר להריץ גם ב-Node.
- `js/views.js`: בניית סוגי המערכות. `js/render.js`: יצירת HTML, PDF, Excel ו-Word.
- `js/importer.js`: קריאת קבצים. `js/pages-*.js`: מסכי הממשק.
- הספריות (SheetJS, pdf.js, JSZip) נמצאות מקומית ב-`js/vendor`.
- הרצת הבדיקות: `npm test`.

## הצעות להמשך

- סנכרון בין כמה מחשבים או משתמשים, עם שרת והרשאות (מנהל, מחנך, מטפל לצפייה בלבד).
- שליחת מערכת אישית להורים ולצוות (WhatsApp או מייל) ועדכון אוטומטי כשמשהו משתנה.
- ייבוא מערכת קיימת מקובץ Word, כולל זיהוי שעות ומפגשים.
- מעקב נוכחות בטיפולים ודיווח שעות טיפול מול תוכנית אישית (תל"א).
- תצוגה עם סמלים ותמונות לתלמידים שלא קוראים (מערכת ויזואלית).
